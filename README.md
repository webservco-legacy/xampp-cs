# XAMPP CS

XAMPP CS 1.0.061001 (October 2006): a Bash script with a menu and command-line options (`xcs --help`) to control
XAMPP for Linux. Published on SourceForge as `xamppcs`. A historical archive, kept read-only: written for the XAMPP
for Linux of 2006 and not maintained since.

## Contents

- `xcs`: the program; `xcs-readme`: its readme (installation, usage, changelog); `xcs-license`: the GNU GPL v2;
- `icon/`: the icon and its sources; `snapshots/`: a screenshot;
- `extra/xamppcs.sourceforge.net/`: the project page, as saved on 2006-12-11.
